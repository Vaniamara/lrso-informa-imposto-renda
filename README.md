# 🦁 Leão Informa


### Ferramenta de Organização de Dados para o Imposto de Renda

---

## 📌 Sobre o Projeto

O **Leão Informa** é uma ferramenta desenvolvida em **Microsoft Excel** com o objetivo de facilitar a organização das principais informações utilizadas na preparação da declaração do Imposto de Renda.

A solução foi criada para centralizar dados cadastrais, informações bancárias, rendimentos e entradas financeiras em uma estrutura simples, organizada e de fácil utilização.

O projeto faz parte de um desafio da **DIO (Digital Innovation One)**, aplicando conceitos de organização de dados, automação em Excel e documentação de soluções.

---

## 🎯 Objetivo

Desenvolver uma ferramenta prática que auxilie o usuário a:

- Organizar informações pessoais;
- Registrar dados de instituições financeiras;
- Controlar rendimentos;
- Registrar entradas financeiras;
- Centralizar informações importantes;
- Facilitar a conferência dos dados;
- Reduzir esquecimentos durante a preparação da declaração.

---

## 💡 Problema Identificado

Durante a preparação do Imposto de Renda, é comum que as informações necessárias estejam espalhadas em diferentes documentos, bancos, informes de rendimentos e anotações.

O **Leão Informa** busca solucionar esse problema criando um ambiente único para organizar essas informações.

### Antes

📄 Informações espalhadas  
🏦 Vários bancos  
🧾 Diversos informes  
📝 Anotações separadas  
🔎 Dificuldade para conferir os dados

### Com o Leão Informa

📊 Informações centralizadas  
🏦 Dados bancários organizados  
💰 Controle das entradas  
📋 Estrutura padronizada  
✅ Maior facilidade de conferência

## ⚙️ Funcionalidades

### 👤 Dados do Titular

Área destinada ao cadastro das informações do contribuinte.

Possui campos para organização de:

- Nome;
- CPF;
- Data de nascimento;
- Título de eleitor;
- Informações de cônjuge;
- Endereço;
- CEP;
- Telefone;
- Celular;
- E-mail;
- Informações relacionadas à declaração.

---

### 🏦 Informes Bancários

Área destinada ao registro das informações financeiras fornecidas pelas instituições bancárias.

Possibilita organizar:

- Instituição financeira;
- Código do banco;
- Valores;
- Informações do informe de rendimentos;
- Totalização dos valores registrados.

---

### 💰 Controle de Entradas

Área destinada ao registro das entradas financeiras.

As informações podem ser organizadas por:

- Data;
- Categoria;
- Descrição;
- Valor.

Essa estrutura permite acompanhar e consolidar os valores registrados durante o período.

---

### 🏛️ Base de Instituições Financeiras

A ferramenta conta com uma base de instituições financeiras para facilitar o preenchimento das informações bancárias.
